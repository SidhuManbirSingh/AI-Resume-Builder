### Canadian Labor Market AI Exposure Map Dashboard | [GitHub](https://github.com/SidhuManbirSingh/canadian-ai-exposure)
*Python | JavaScript | Gemini API | Data Pipeline | HTML5/CSS3*

- Engineered an interactive labor market analytics portal mapping AI and LLM automation risk across 500+ National Occupational Classification (NOC 2021) occupations.
- Ingested, cleaned, and standardized census and Labour Force Survey (LFS) tables from Statistics Canada into structured JSON databases.
- Developed an automated Python scoring pipeline leveraging Google's Gemini 1.5 Flash API to evaluate occupational task checklists for automation exposure.
- Designed an interactive responsive treemap visualization sizing sectors by employment volume with multi-tiered color coding (high, medium, low risk).
- Architected an offline-safe local runtime architecture eliminating backend server dependencies for zero-friction distribution.
