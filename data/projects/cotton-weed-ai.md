### Cotton Weed Detection AI Computer Vision Pipeline (Capstone Project) | [GitHub](https://github.com/SidhuManbirSingh/Cotton-Weed-Prediction-Model)
*YOLOv8 | PyTorch | Python | OpenCV | Flask | React | OpenVINO | Docker Compose (51 Commits)*

- Built and trained an end-to-end deep learning computer vision Capstone pipeline across 51 Git commits utilizing YOLOv8n to analyze high-resolution UAV/drone imagery for precision agriculture.
- Achieved 0.8489 overall mAP@50 (93.8% mAP@50 for cotton crop detection and 76.0% for weed detection) at an ultra-low 3.1ms inference speed.
- Developed a full-stack web application featuring a React frontend with synchronized side-by-side original vs. annotated video playback and a Flask REST API backend.
- Accelerated real-time inference using Intel OpenVINO model optimization and engineered asynchronous background workers for frame extraction and annotated video reassembly.
- Fully containerized the React frontend, Flask backend, and OpenVINO/PyTorch inference engine using Docker Compose for reproducible cross-platform deployment.
