### Community Event Management System CLI
*C++ | Object-Oriented Programming | Polymorphism | CLI*

- Developed a robust C++ console application implementing object-oriented programming (OOP) principles including abstraction, polymorphism, and encapsulation.
- Created an abstract User base class with pure virtual interface methods inherited by specialized CommunityMember and Administrator roles.
- Implemented role-based workflows enabling administrators to publish events and approve/reject applications while members submit requests and track statuses.
- Enforced data integrity through private class attributes, accessor/mutator methods, and defensive input processing loops.
