### Glossy Rides Detailing Single-Page Web Application | [GitHub](https://github.com/SidhuManbirSingh/glossy-rides)
*React 18 | JavaScript | Axios | CSS3 | REST APIs | Responsive UI*

- Engineered a responsive single-page application (SPA) using React 18, React Hooks, and modern component architecture.
- Implemented an interactive appointment booking form with comprehensive client-side validation and dynamic error handling.
- Integrated RESTful API service layers with Axios for appointment submissions, blog content syndication, and contact routing.
- Designed an accessible UI featuring smooth scrolling navigation, dark mode toggling, and interactive expanding image galleries.
- Optimized asset loading and frontend bundle delivery for sub-second page loads across modern browsers.
